About this demo

A tiny interpreter (renderer.js) fetches catfish-ui.xml, walks the widget tree and maps every LVGL-flavored attribute to DOM at the panel’s true 800×480. The on-device UI itself is hand-written LVGL v8 C code — this XML is the design source of truth.

Try it

  • Hold FEED NOW ~1 s — the amber fill mirrors the firmware’s 800 ms hold-to-confirm; a quick tap just toasts.
  • Flip 12-hour clock and Vacation in Settings — the status-bar clock and the Home badge react like the real unit.
  • Scan for relays mimics the LAN UDP broadcast feedback.
