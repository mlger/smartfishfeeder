Catfish Feeder — Web Flasher

Install the latest Catfish Feeder firmware straight from your browser — no toolchain, no drivers to hunt down, no command line. Everything is served from this page.

Display Unit

ESP32-S3-Touch-LCD-4.3B (ESP32-S3-WROOM-1-N16R8)

The 4.3″ 800×480 touch panel: pond dashboard, feeding schedule, manual feed trigger.

Web Serial is not available in this browser. Use Chrome, Edge or Opera on a desktop computer. Flashing requires a secure context — open this page over HTTPS.

Connect via USB, then click Install and pick the board’s serial port when the browser asks. Works in Chrome, Edge or Opera on desktop (Web Serial); Firefox and Safari are not supported.

First install or switching firmware? Tick “Erase device” in the install dialog — this wipes old settings and filesystem cleanly.

Relay Unit

ESP8266 NodeMCU V3

The feeder motor driver: receives feed commands from the Display Unit over Wi‑Fi and pulses the relay.

Web Serial is not available in this browser. Use Chrome, Edge or Opera on a desktop computer. Flashing requires a secure context — open this page over HTTPS.

Connect via USB (micro‑USB on the NodeMCU), then click Install. Works in Chrome, Edge or Opera on desktop (Web Serial).

Tick “Erase device” in the install dialog when prompted to clear saved Wi‑Fi credentials and old firmware.

Troubleshooting

Port never shows up (Display Unit, ESP32-S3)

  • The 4.3B uses native USB (no UART bridge). Hold the BOOT button on the board while plugging in the USB cable, then release it — the ESP32-S3 then enumerates as a serial device and flashing can start. Press RST once the install finishes.
  • Use a data USB cable, not a charge-only cable — this is the single most common cause of a missing port.

Port never shows up (Relay Unit, NodeMCU)

  • The NodeMCU uses a USB-to-serial bridge (CP2102 or CH340). If no port appears, install the CP210x or CH340 driver for your OS.
  • On Linux the user needs dialout group membership to open serial ports.

Install starts but fails / times out

  • Try a different USB port (direct on the computer, not through a hub) and a short, known-good cable.
  • Close any other program that may hold the serial port open (serial monitor, Arduino IDE, PlatformIO).
  • On the NodeMCU, if the board never enters the bootloader, hold the FLASH button while the installer says “Connecting…”, then release.
  • Tick “Erase device” and retry — a corrupt previous flash or old filesystem can block installs.

After a fresh install

  • First boot starts a Wi‑Fi setup access point (captive portal) — join it with your phone or laptop to configure the pond’s Wi‑Fi credentials.
  • The Display Unit may take ~10–20 s to boot the first time after an erase (filesystem formatting).
